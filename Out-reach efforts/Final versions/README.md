# Final versions

This folder is for Nitesh only. The nightly ProfitPulse outreach run never writes here.

When a deck is edited into its final, sent ready form, save it in this folder using the
same date stamped file name as the original run output (for example
`Brief_Sniip_19Aug2026.pptx`). The original run output stays in the parent folder, so the
two sit side by side for later comparison, and recurring edits can be fed back into the
nightly run instructions as new rules.
